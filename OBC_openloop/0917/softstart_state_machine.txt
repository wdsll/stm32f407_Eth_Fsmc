LLC 开环软启动详细设计
软启：200kHz → 130kHz，300ms 半余弦，1ms tick
谐振点：fr ≈ 91kHz
sweep：计划 130kHz → 75kHz
负载档：空载/5A/10A/20A/40A
过流：41A（你这里基本等同“硬上限”）
重点结论先说：40A 档因为离 41A 只有 1A 裕量，不建议扫过 95~90k 这段敏感区。 找 fr / 曲线用 5A~20A 档完成；40A 档只做“fr 上方验证点”更安全。

1.开环调试的总流程（状态机）
	IDLE：MOE=0，PWM关，等待启动命令
	PRECHARGE（自举预充）：低侧先导通 1–3ms（bootstrap pre-charge）
	SOFTSTART_RAMP：200k → 130k，300ms 半余弦曲线
	HOLD_STABLE：130k 保持 100–200ms（让 Vout/Iout/Ipri 稳）
	SWEEP：从 130k 逐步扫到目标下限（按负载档限制不同）
	HOLD_END：保持在最后一个安全频点（或回到 130k）
2.软启段详细参数（你现有方案 OK）
	tick：1ms
	duration：300ms
	曲线：k=0.5*(1-cos(pi*t/T))
	f = f_start + (f_target - f_start)*k
	f_start=200kHz，f_target=130kHz
	软启结束后不要立刻 sweep，先 HOLD 130k 100–200ms（避免你采到的是动态过程）。
3.sweep 段策略（按 fr≈91kHz 分段 + 按负载档限界）
	因为 接近 fr（91kHz）附近“增益斜率最大”，开环往下扫很容易让电流猛涨，尤其半载/满载。
	段A（远离fr，上方安全区）：130k → 105k
	段B（接近fr 上方）：105k → 95k
	段C（穿越敏感区）：95k → 88k（包含 fr≈91k）
	段D（fr 下方）：88k → 75k（风险更高）
4.每个负载档的“sweep 下限”
	目标：既能定位 fr，又不被 41A 卡死、也不冒险扫到危险区。
	空载   90k~85k（先别扫到 75k）  空载时 Vout 可能飙高，先看电压上升和波形，不追求扫很低
	5A     75k（可以全扫)           风险小，可用于完整曲线与 fr 定位
	10A    80k~75k                  一般也可全扫，但穿越 fr 段要更慢
	20A    88k~85k（建议先到这里)   20A 扫到 75k 风险明显升高，建议以“刚过 fr”就足够
	40A    95k 或 100k 停止         强烈不建议扫到 91k 附近：41A 只剩 1A 裕量，任何过冲就触发
5.sweep 的步进与停留（dwell）建议
5A / 10A（用来拿完整曲线）
	段A 130→105：步进 2k，dwell 20–30ms
	段B 105→95：步进 1k，dwell 50–80ms
    段C 95→88：步进 0.2–0.5k，dwell 100–200ms（关键）
	段D 88→75：步进 0.5–1k，dwell 80–150ms
20A（用来验证负载影响 + 较安全定位 fr）
	段A 130→105：步进 2k，dwell 20–30ms
	段B 105→95：步进 1k，dwell 50–80ms
	段C：步进 0.2–0.5k，dwell 150–250ms
	建议到 88k~85k 就停（别硬扫到 75k）
40A（只做高于 fr 的验证）
	130→110：2k / 20–30ms
	110→100：1k / 50–80ms
	100→95：0.5k / 100–150ms
    到 95k（或 100k）停止并 HOLD
6.必须加入的“开环扫频限流/保命逻辑”（按 41A 上限设计）
你给的 OCP=41A，满载 40A 离得太近，所以必须做“软钳位”，不然 sweep 会被轻易打断。
建议三段阈值（以 Iout 为例；如果你用的是一次电流/谐振电流，也同理）：
	I_pause：到这个就暂停继续降频（hold 当前频点，延长 dwell）
	I_backoff：到这个就回拉升频（比如 +2k~+5k，回到上一个安全点）
	I_trip：到这个就停机（MOE=0，故障）
	按你的负载档给一套“可直接用”的建议值：
	5A 档 	I_pause = 8A  I_backoff = 10A I_trip = 12A（软件先挡住，别等硬件 41A）
	10A 档  I_pause = 14A  I_backoff = 16A I_trip = 18A
	20A 档  I_pause = 24A  I_backoff = 26A I_trip = 28A
	40A 档（最关键）：I_pause = 40.3A  I_backoff = 40.6A I_trip = 40.9A（别碰 41A，给硬件留一点时间裕量）
注意：如果你电子负载是 CC 模式，稳态 Iout 不会涨太多，但穿越 fr 的瞬态峰值仍可能冲上去，所以这些阈值是为了抓瞬态。
还建议加一个时间判据减少误判：I > I_trip 持续 2–5ms 再停机（但 BKIN/硬件保护照样瞬停）
7.采样记录：
	推荐每个频点 dwell 的最后 10–20ms 做平均：f_cmd，Vbus，Vout_avg（dwell末端平均），Iout_avg，Iout_peak（dwell期间峰值，判断是否接近保护）
可选：Ipri_avg / Ires_avg（更能反映谐振敏感区）
    在固定负载档、固定 Vbus 下，找 Ipri_peak 或 Vout 对频率的“峰值/拐点”附近就是 fr（但注意 fr 会随负载略漂）
