# PFC 阶段验证汇报（08-28）· 完善版

> 测试模式：纯硬件使能（NCP1654 直接上使能，MCU 未参与）

## 一、阶段结论

PFC 成功上电并完成满载验证，**1500W 额定点达成**，功率级（SiC MOS + IVCR1402Q 驱动 + 升压电感）工作正常。

## 二、测试条件与数据

**测试条件**：输入 230V / 165V 工频交流，NCP1654 峰值电流模式控制（开关频率 ~133kHz），SiC MOS + 负压关断驱动，输出母线电压闭环稳定。

| 项目 | 数据 | 判读 |
|---|---|---|
| 额定输入 230V | 满载 **1500W** 稳定运行 | 额定点达成 |
| 功率因数 PF | **0.992**（满载） | 优于 ≥0.99 典型设计指标 |
| 低压 165V | 持续输出 **1300W** | 触及交流源 8.4A 限流理论上限，**属测试设备约束而非整机能力** |
| 效率 | 0.94（**预估口径**） | 待带载实测标定 |
| SiC 驱动 Vgs | +17.5V / 关断 −4.97V | 负压关断正常工作 |
| Vds 波形 | 关断平台干净、母线稳定 | 开关特性正常 |
| 电感电流 | 工频包络基本正弦 | 支撑 PF=0.992 |

**低压 1300W 根因说明**：输出 1500W、η=0.94、PF=0.992 时所需输入电流 = 1596/(165×0.992) ≈ 9.75A，超过交流源 8.4A 限流；实测 1300W 与理论天花板 1290W 吻合，说明功率路径在低压输入下已跑到源允许的极限。

## 三、待优化项

电感电流在工频过零附近存在畸变（CCM/DCM 交接区，NCP1654 峰值电流控制典型现象），对 THD 与轻载 PF 有影响。优化路径：调整 NCP1654 电流环外围参数（电流检测 RC 滤波、斜坡补偿、增益设定），**不涉及功率级硬件改动**。

## 四、需要的支持

现交流源限流 8.4A，**申请协调大功率可编程交流源**（165V 输入时 ≥10A，容量 ≥3kVA），以完成低压输入额定点验证。

## 五、下一步计划

1. 借助大功率交流源，完成 165V 输入额定点验证；
2. 优化电流过零畸变：满载 PF 保持 ≥0.99，THD 显著改善；
3. 效率实测标定（替换当前 0.94 预估口径）；
4. 转入整机软件联调（保护逻辑、CC/CV 时序、串口调试链路）。
