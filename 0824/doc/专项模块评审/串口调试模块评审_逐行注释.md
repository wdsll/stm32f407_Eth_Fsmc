## 三、问题清单（按严重度 + 落实状态）

### P1（上板前必须确认，否则功能异常）
1. **浮点 printf 库开关**：`print_status` 用了 `%f`。armclang/Keil 默认不链接浮点 printf，未开启时 `%f` 打印空或乱码。`main.c:7` 已注明需勾 **MicroLIB**（或 armclang 加 `--printf_float`）。**状态：文档已标注，需人工勾选 Options→Target→Use MicroLIB（未自动验证）**。

### P2（建议初版内修，不影响上板但不修会有困惑/边界隐患）
2. **CLEAR 的死注释（103-108 行）**：过时且误导，建议删除或把说明挪到 `protect.c` 的 `protect_clear_fault` 旁。当前行为由 START 把关安全，但注释误导维护者。**状态：未落实，注释仍在**。
3. **SET 电压上限 80V 与 OVP 64V 不一致（68 行）**：建议上限收到 ≤60V。**状态：未落实，仍是 80V**。
4. **控制台看门狗「无人值守充电 5s 自停」（153-157 行）**：自动状态打印不刷新看门狗计时。建议二选一：① 状态打印也 pet；② 超时放宽到 10~30s；③ 文档写清「需周期 PING」。**状态：未落实**。
5. **RX 无 FIFO 高速丢字**：人工联调无影响；脚本高速发命令建议改中断/DMA 收。**状态：初版可忽略，未改**。

### P3（后续扩展注意）
6. **环形缓冲无临界区保护（debug_printf.c:11-14）**：当前只有任务上下文写 head，安全。ISR 里调 `debug_printf` 需加 `__disable_irq()/__enable_irq()`。**状态：未变**。
7. **无本地回显**：终端敲命令看不到输入字符，联调体验略差。可在收到可打印字符时 `debug_printf("%c",ch)` 回显。**状态：未实现（可选）**。
