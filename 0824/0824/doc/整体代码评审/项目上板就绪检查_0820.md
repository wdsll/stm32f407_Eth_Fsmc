## 二、联调驱动链路（bench，CAN 已注释）
```
串口 SET→START→[状态机自动流转]→STOP / CLEAR
  SET  <volt> <amp>   限定 10..80V / 0..20A，先 STOP 再设
  START               需先 SET 且非 FAULT
  STOP                撤销 enable
  CLEAR               清锁（阻塞 15ms 脉冲），再 START
  5s 看门狗           使能中 5s 无命令自动 STOP
```
串口参数：**115200 / 8N1 / USART2（PB10=TX, PB11=RX，GD32 默认脚，无需重映射）**。
> ⚠ 注意：0917 是 230400，0824 是 115200，别混。

## 三、状态机流转（确认可闭环）
STANDBY →(vbat≥10V & enable) PRECHARGE →(bus≥360V 或 3s 超时) CC →(电压到基准-0.5V 持续1s) CV →(电流≤1A 持续30s) FINISHED
FAULT：STOP+CLEAR 清锁后，tick 顶部自动回 STANDBY。

## 四、上板前 Checklist（P0，必做）
1. **电池端 vbat ≥ 10V**：接「稳压电源（设电池电压）∥ 电子负载」模拟电池；只接纯负载不接电压源会永远卡 STANDBY。
2. **PFC 母线稳压点 ≥ 360V**：先确认硬件 NCP1654 反馈网络把母线稳在 ~380–400V；否则 `VBUS_MIN_START_V=350` 达不到 → 3s 超时锁 FAULT。
3. **串口 115200/8N1** + 勾选 **MicroLIB**（否则 printf 不输出）。
4. 上电后先发 `STATUS` 看 ac/bus/out/bat/i 五路采样是否真实跳动（确认 ADC 接线）。
