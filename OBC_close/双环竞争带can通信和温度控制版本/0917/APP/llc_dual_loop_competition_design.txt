# LLC 电压/电流双环竞争设计说明
## 1. 目标
- **稳压优先、限流兜底**：在额定负载下以电压环保持输出电压，负载突变或短时过载时由电流环限制输出电流，避免过流并保持系统稳定。
- **统一执行量**：双环最终都输出 LLC 频率指令，通过“竞争”选择更保守的频率，保证安全性与稳定性。
- **可调参数**：电压环/电流环 PI 参数、目标值和频率限制均可通过宏定义快速调整。

## 2. 信号与采样
- **电压测量**：`g_adc_multi.vout_raw` → `s_llc_rt.meas.vout_v`。
- **电流测量**：`g_adc_multi.isense_raw` → `s_llc_rt.meas.iout_a`。
- **母线电压**：`pfc_bus_voltage()` → `s_llc_rt.meas.vbus_v`。
- **控制周期**：1 kHz，入口函数 `llc_app_tick_1khz`。

## 3. 双环控制结构
### 3.1 电压环（V-loop）
- **误差定义**：`v_err = v_ref - v_meas`。
- **PI 输出**：`u_v = v_kp * v_err + v_integ`，`v_integ += v_ki * v_err`。
- **频率映射**：`f_v = f_nom - u_v`，并限幅到 `[f_min, f_max]`

### 3.2 电流环（I-loop）
- **误差定义**：`i_err = i_ref - i_meas`。
- **PI 输出**：`u_i = i_kp * i_err + i_integ`，`i_integ += i_ki * i_err`。
- **频率映射**：`f_i = f_nom - u_i`，并限幅到 `[f_min, f_max]`。

> 说明：当输出电流超过目标值时，`i_err < 0`，`u_i` 变小（或为负），从而提升 `f_i`，降低 LLC 变换器增益，实现限流。

## 4. 竞争策略（双环竞争）
### 4.1 竞争原则
- **频率越高，输出能力越弱**（在 LLC 典型工作区间成立）。
- 因此，**取较大的频率指令** 作为最终指令：
  - `f_cmd = max(f_v, f_i)`。
  - 当电流环需要限流时，`f_i` 通常大于 `f_v`，从而电流环胜出。
  - 负载较轻时 `f_v` 主导，系统表现为稳压。
  
### 4.2 积分更新策略
- **胜出环更新积分**，落败环保持积分值，避免无谓积分带来的 windup。
- 当 `f_v == f_i` 时，两个环均可更新积分。

### 4.3 斜率限制
- 对最终 `f_cmd` 执行频率斜率限制（`LLC_F_SLEW_HZ`），避免频率突变导致的磁件冲击或振荡。
