
# LLC 闭环控制详细设计报告

## 1. 设计目的与范围
本报告基于提供的 Simulink 脚本与控制框图，更新项目中的 LLC 控制参数与实现逻辑，给出闭环电压/电流控制、软启动与限流接管的详细设计说明，并对关键参数与离散实现方式进行归纳。

## 2. 控制结构概述
### 2.1 总体闭环结构
闭环由两条主回路组成：
- **电压环（主环）**：PI + anti-windup + 频率斜率限制（slew）+ 量化；在电流限流接管时进入 tracking 模式，避免积分风up。
- **电流环（限流环）**：基于电流误差的 PI 输出频率增量 `df_i`（只允许 ≥ 0），通过“升频限流”的方式抑制输出电流。

最终频率命令：
```
F_cmd = max(F_v_cmd, F_min + df_i)
```
其中 `F_v_cmd` 为电压环输出，`F_min + df_i` 为电流限流输出。

### 2.2 软启动与切换
软启动按照设定时间从起始频率过渡到目标频率，并在软启动结束后进入 **RUN_ENTRY_HOLD**（稳定保持）状态。
进入闭环运行时，以软启动末拍频率为 `f_init`，电压环通过 bumpless 初始化确保无扰接管。

## 3. 电压环设计
### 3.1 控制律（离散）
电压环控制为：
```
error = Vref - Vout
PI: u = Kp*e + sum(Ki*e)
F_req = F_nom - u
```
- `F_req` 经过饱和（`F_min~F_max`）后再进行 slew 限幅。
- 使用 **deadband** 降低测量噪声对控制的影响。
- 输出支持量化（`F_q_step`）以与数字系统频率步进对齐。

### 3.2 限流接管 tracking
当电流环进入限流状态时：
- 电压环 **不再积分**，而是跟踪 `F_track`（上周期真实输出），反算积分值，防止 windup。
- Slew 的起点同步到 `F_track`，避免输出被斜率限制“卡住”。

### 3.3 电压环参数
| 参数 | 数值 | 说明 |
| --- | --- | --- |
| Kp | 1400 | 电压环比例 |
| Ki | 100 | 离散积分增量 (Hz/step)/V |
| F_min | 75 kHz | 最小频率 |
| F_max | 150 kHz | 最大频率 |
| F_nom | 100 kHz | 额定频率（与软启动末拍对齐） |
| F_slew | 1000 Hz/step | 频率斜率限制 |
| E_db | 0.15 V | 电压死区 |
| F_q_step | 100 Hz | 频率量化步进 |

## 4. 电流环设计
### 4.1 控制目标
仅在输出电流超过阈值时输出频率增量 `df_i (>=0)`，通过升频降低增益，实现限流。

### 4.2 Hysteresis 触发逻辑
为避免临界点来回切换，采用双阈值滞回：
- 进入限流：`I_out >= I_on`
- 退出限流：`I_out <= I_off`

### 4.3 控制律（离散）
```
I_err = I_out - I_ref
u = Kp_i * I_err + sum(Ki_i * I_err)
df_i = clamp(u, 0, df_max)
```
- `df_i` 经过 `df_slew` 限制上升/下降斜率。
- 非限流状态下 `df_i` 目标为 0，通过 slew 平滑释放。

### 4.4 电流环参数
| 参数 | 数值 | 说明 |
| --- | --- | --- |
| I_ref | 20 A | 电流参考 |
| I_err_sat | 5 A | 误差限幅 |
| Kp_i | 400 | 电流环比例 (Hz/A) |
| Ki_i | 1200 * Ts | 1.2 Hz/A/step (Ts=1ms) |
| df_max | 75 kHz | 最大升频增量 |
| df_slew | 3e6 * Ts | 3000 Hz/step |
| I_on | I_ref + 0.5 A | 进入限流 |
| I_off | I_ref - 1.0 A | 退出限流 |

## 5. 软启动设计
### 5.1 目标与参数
软启动频率由高频逐渐下降至目标频率，并确保与电压环 `F_nom` 对齐：
- 软启动目标频率：100 kHz
- 软启动时间：30 ms
- 软启动稳定等待：0 ms

### 5.2 接管逻辑
软启动结束后，系统进入 RUN_ENTRY_HOLD，等待电压稳定后进入闭环。

## 6. 与代码实现的对应关系
### 6.1 关键映射
- 电压环 PI + slew + 量化：`llc_ctrl_step()`
- 电流环限流输出 `df_i`：`llc_current_limit_step()`
- 软启动与闭环切换：`ST_SOFTSTART` → `ST_RUN_ENTRY_HOLD` → `ST_LLC_RUN`

### 6.2 输出合成
在 `ST_LLC_RUN` 中执行：
```
f_cmd = max(f_cmd_v, f_min + df_i)
```
确保限流升频优先级高于电压环输出。

## 7. 风险与注意事项
- 电压/电流参数需与实际硬件额定值匹配，特别是 OVP/OCP 门限。
- `F_slew` 与 `df_slew` 应结合 PWM 频率更新分辨率与系统响应速度评估。
- 进入/退出限流时，tracking 逻辑确保闭环平滑切换，但仍需结合实际负载进行验证。

## 8. 结论
本次更新将 Simulink 控制策略映射至 MCU 代码，统一参数并实现电压环与电流环的协同控制。
电流限流采用升频方式并增加滞回/释放 slew，有助于稳定限流边界。
电压环增加 deadband、量化与 tracking，可有效降低噪声敏感性与 windup。
